<h2>Just A Lil Guy (trying not to die)</h2>

This is a simple platformer game I made by learning the basics of Godot for the first time on my own! The rat and start screens are drawn by me while the backgrounds for the scenes and the blocks are from free itch.io assets (credits given in game)

I was inspired to make this because I think rats are the most adorable lil guys, and I was excited to animate a game character that I drew and designed myself :D

game link: https://chxuri.itch.io/just-a-lil-guy-trying-not-to-die

Game Controls: Use either WAD to move up, left, and right or the arrow keys!
